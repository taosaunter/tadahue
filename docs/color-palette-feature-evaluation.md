# Color Palette — 功能方向

更新：2026-09-30

## 核心任務

使用者選色後，要能立即判斷配色放進實際介面的效果。主要預覽情境為儀表板、品牌／形象頁、表單。緊湊桌面 UI 的目標是減少垂直堆疊，同時保留色輪操作和即時 UI 預覽。

ColorSlurp 可作為緊湊操作、色票速覽與工具分區的參考，不照搬其視覺、窄小視窗或圖片取色／對比檢查頁面。

## 已實作的介面決策

- **色輪：**五個控制點；中間兩個為使用者指定色，外側三個依配色關係生成。互補色、分裂互補色與三角色均以五色呈現。拖曳後即時更新色票與情境預覽。
- **工作區：**啟動時只顯示窄版色輪面板，展開按鈕會加寬視窗並顯示預覽。右側提供預覽／微調／完整色票／更多配色／已存色板五個頁籤；預覽與色票跟隨主題切換。
- **工具列：**色輪頂部放吸管、風格下拉、語言、主題、展開／收起；底部以圖示放 JSON、CSS、Tailwind 複製與儲存，提供懸浮和聚焦提示。
- **WCAG：**保留內部計算／品質檢查；移除介面中的達標展示、檢查清單和提示。
- **微調：**位於右側頁籤，提供亮度與 OKLCH 色相／明度／彩度操作；更新後的色票 HEX 以懸浮／聚焦提示查看。
- **色票與色板庫：**完整色票採 4 行 × 7 列，窄版改 7 行 × 4 列；色票／更多配色使用 `rounded-lg p-2`，移除色票下方文字。色板庫位於右側頁籤，點擊色帶載入完整 snapshot。

## 目前實作

已實作：Dashboard／Landing／Form 預覽、light／dark／both 顯示、28 個語義角色、WCAG 計算、三種 preset（balanced、pastel、vintage）、全域 OKLCH 微調、JSON／CSS／Tailwind 生成及本機色板快照。

本輪已完成窄版啟動、視窗展開／收縮、頂部工具列、底部圖示操作、右側五個頁籤、主題連動預覽，以及 28 色票整齊排列。

兩個指定色的色相依所選關係連動，飽和度／亮度可各別調整；第二色映射至 accent。色輪採 HSV，主題採 OKLCH；最終主題色因風格、微調與對比修正，可能不同於輸入 HEX。

## 驗證順序

1. 原型比較選色後查看儀表板、形象頁、表單，哪種情境最能幫使用者判斷配色。
2. 驗證兩個輸入色與三個生成色的色輪操作是否易懂，拖曳後是否能立即理解結果。
3. 確認使用者能看懂微調後 HEX、複製格式和色板點擊載入。

約五組 preset、角色級微調、局部重生、圖片取色和 APCA 都仍是候選，不是已確認需求；先不排入本輪介面整理。

## 研究依據

Reddit 研究最強的訊號是實際 UI 情境預覽、對比／可讀性與語義色彩。這些是需求證據，不代表必須把完整 WCAG 檢查清單放在介面。研究中沒有明確付費意願；不以本研究為由加入訂閱牆或團隊雲端功能。詳見[研究報告](./reddit-color-pairing-report.md)。
