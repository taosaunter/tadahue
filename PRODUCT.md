# TadaHue

TadaHue is a desktop color toolkit for designers and frontend developers. It turns a starting color into harmonious palettes and semantic light and dark themes, then helps users inspect contrast, preview interface examples, refine colors, and export usable code.

The app supports local image color extraction and native screen picking, OKLCH tuning, a local library of up to 20 palettes, and CSS, Tailwind configuration, or JSON export. Color processing and saved palettes stay on the user's device. The app has no accounts, analytics, cloud sync, or collaboration features.

The visual system should make the live palette easy to inspect while keeping controls readable and neutral. It should preserve the distinction between the stable app interface and the generated theme being evaluated.
